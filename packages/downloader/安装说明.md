# 安装说明

这个包是 [dsh-workbay](../..) monorepo 的一部分（`packages/downloader`）。
完整功能说明见 [README.md](README.md)，设计细节见 [架构与实现说明.md](架构与实现说明.md)。

## 一、包里有什么

```
dsh-downloader/
├─ package.json                          插件清单（dsh.bundle.patch + dsh.client）
├─ cordis.patch.yml                      挂载配置（一行 insert）
├─ lib/index.js                          Host 半侧（串口 / 烧录 IPC / HTTP / SSE / 日志）
├─ lib/client.js                         Client 半侧（Downloader 面板）
├─ helper/AbSerialHost.exe               串口 helper（64 位 .NET）
├─ helper/AbSerialHost.cs                其源码
├─ ipc-helper/DownloaderIpcBridge.exe    烧录 IPC 桥（32 位 .NET，必须 x86）
├─ ipc-helper/DownloaderIpcBridge.cs     其源码
├─ smoke-test.mjs                        后端自检（未配置路径时相关用例 SKIP）
├─ http-test.mjs                         接口测试
└─ README.md                             使用与排查
```

两个 exe 都是零依赖编译的（只用 .NET Framework 自带类库），不需要安装运行时。

## 二、前置条件

| 项目 | 要求 |
|---|---|
| DSH 桌面版 | `>=0.2.1-rc.1 <0.3.0-0` |
| `dsh-workbay-dock` | 已安装（本插件作为它的一个页面注册） |
| 厂商 Downloader | v3.6.0 已验证；路径由 `DSH_DOWNLOADER_DIR` 指定 |
| 串口驱动 | CP210x / CH34x / FTDI 任一（蓝牙虚拟串口不能用） |

## 三、安装

```powershell
# 1) profile 的 package.json 加两处：dsh.profile.bundles 里加 "dsh-downloader"，
#    dependencies 里加 "dsh-downloader": "file:<repo>/packages/downloader"
cd $env:USERPROFILE\.dsh\profiles\desktop
pnpm install

# 2) 配置本机路径（写进用户环境变量，DSH 启动时继承）
[Environment]::SetEnvironmentVariable('DSH_DOWNLOADER_DIR', '<你的 Downloader 安装目录>', 'User')
[Environment]::SetEnvironmentVariable('DSH_DOWNLOADER_WORKSPACE', '<你的 SDK 工程根目录>', 'User')

# 3) 完全退出并重启 DSH
```

安装后「工作台」面板里出现 **Downloader** 页签即成功。

## 四、验证

```powershell
cd packages/downloader
node smoke-test.mjs     # 后端：目录扫描 / git 元数据 / 串口 helper / 烧录 IPC
node http-test.mjs      # HTTP：各接口返回值
```

没设 `DSH_DOWNLOADER_WORKSPACE` / `DSH_DOWNLOADER_SAMPLE_REPO` 时，相关用例自动 SKIP，
不影响其余用例。串口用例需要真实插着的板子。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 没有 Downloader 页签 | 没重启 DSH / bundles 里漏了 | 检查 profile 的 `dsh.profile.bundles` |
| 一直显示离线 | Downloader 的 `COMEnable=False` | 插件会自动修正；也可调 `/flash/fix-comenable` |
| `/diag` 报 Downloader 目录缺失 | 没设 `DSH_DOWNLOADER_DIR` | 设环境变量后重启 DSH |
| 卡在「扫描中」 | 板子休眠了 | 重新上电 / 按复位 |
| 串口打不开 | 被 Downloader 或串口助手占着 | 先点断开；或关掉其他串口程序 |
| 装完起不来、报找不到 kit | profile 缺 `@dsh-workbay/kit` | 用 `pnpm install` 装，别手工拷贝目录 |

## 六、改代码后何时生效

| 改动文件 | 生效方式 |
|---|---|
| `lib/client.js`（界面） | 刷新页面即可 |
| `lib/index.js`（Host） | 重新 `pnpm install` + 重启 DSH |
| `helper/*.exe` | 重新编译后重启 DSH |

```powershell
# 串口 helper（64 位）
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:exe /platform:anycpu `
  /r:System.dll /out:helper\AbSerialHost.exe helper\AbSerialHost.cs

# IPC helper（32 位，必须 x86）
C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe /nologo /target:exe /platform:x86 `
  /out:ipc-helper\DownloaderIpcBridge.exe ipc-helper\DownloaderIpcBridge.cs
```
